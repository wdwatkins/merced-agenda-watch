# Merced Agenda Watch

Weekly digest of new City of Merced **City Council** and **Planning Commission**
meeting agendas — flagging annexations, street design / bike & pedestrian
infrastructure, big-picture city finance, and General Plan Update items.
Generated automatically every Friday evening by a Claude Code cloud routine.
